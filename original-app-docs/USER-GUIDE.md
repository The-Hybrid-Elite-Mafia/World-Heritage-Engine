# Create your own instrument
1. Import sample or Scan folder for WAV, FLAC or AIFF recordings. Original recordings are never modified.
2. Select each sample and edit Root, Low key, High key, Low velocity, High velocity and Round robin; click Apply mapping. Review inferred mappings.
3. Enter source/owner/license provenance. Shaping sliders affect recorded sound; they do not synthesize a replacement instrument.
4. Save instrument and enter its name. The suggested library/User Instruments folder appears in Library. Keep the original recordings because the preset references them. Loading and saving preserve mapping and shaping.
5. To play later, confirm provenance, explicitly Connect the saved audio driver, then use the on-screen keyboard, computer keys or Connect MIDI. Startup is stopped; saving an audio choice does not start audio. No hardware playback testing is claimed.

The installed 79-named-type/402-preset collection includes steel- and nylon-string guitar as separate named types (78 if collapsed). It is not every instrument in the world. Samples retain their individual CC0, CC BY4 and GPL-with-composition-exception notices.

Uninstall retains all library files, your instruments, settings and any changed program files. User recordings outside this folder are never touched. Source and dated rollback builds are preserved separately.
